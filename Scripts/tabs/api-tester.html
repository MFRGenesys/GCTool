        Format du dataset et regles supportees
        
      

      

        
Le moteur supporte les regles sur query params et body JSON avec equals, contains, exists et regex, ainsi que les groupes all (AND) et any (OR). Les captures regex peuvent etre reutilisees dans la reponse.

        
{
  "matchMode": "rules",
  "cases": [
    {
      "name": "GET customer regex",
      "when": {
        "all": [
          {
            "source": "query",
            "field": "customerId",
            "operator": "regex",
            "value": "^CUST-([0-9]{3})$"
          },
          {
            "any": [
              {
                "source": "query",
                "field": "segment",
                "operator": "equals",
                "value": "VIP"
              },
              {
                "source": "query",
                "field": "segment",
                "operator": "contains",
                "value": "PREMIUM"
              }
            ]
          }
        ]
      },
      "responseStatus": 200,
      "responseBody": {
        "status": "Success",
        "customerSequence": "${captures.query.customerId.1}",
        "trackingId": {
          "$regexGenerate": "^TRACK-[0-9]{6}$",
          "$type": "string"
        },
        "trackingBatch": {
          "$regexGenerate": "^TRACK-[0-9]{4}$",
          "$regexGenerateCount": 3,
          "$type": "string"
        },
        "seededEmail": {
          "$fakerType": "email",
          "$randomSeed": "${request.query.customerId}"
        }
      }
    },
    {
      "name": "POST customer body",
      "when": {
        "all": [
          {
            "source": "body",
            "field": "customer.id",
            "operator": "regex",
            "value": "^(?CUST)-([0-9]{4})$"
          },
          {
            "source": "body",
            "field": "customer.segment",
            "operator": "contains",
            "value": "VIP"
          }
        ]
      },
      "responseStatus": 201,
      "responseBody": {
        "status": "Created",
        "prefix": "${captures.body.customer.id.groups.prefix}",
        "customerId": "${captures.body.customer.id.2}",
        "token": {
          "$regexGenerate": "^TOK-[A-Z]{4}-[0-9]{4}$",
          "$type": "string"
        },
        "contacts": {
          "$fakerType": "email",
          "$regexGenerateCount": 2
        }
      }
    }
  ],
  "defaultResponse": {
    "responseStatus": 404,
    "responseBody": {
      "status": "NoMatch"
    }
  }
}

        
Legacy: un objet match simple reste accepte et est interprete comme une serie de equals sur les query params. Les placeholders utiles sont ${captures.last.1}, ${captures.query.customerId.1}, ${captures.body.customer.id.groups.prefix} et les generateurs de reponse utilisent {$regexGenerate, $regexGenerateCount, $randomSeed, $fakerType, $type}. Faker type est un contrat local inspire des bibliotheques Faker, pas un standard Genesys/OpenAPI.
